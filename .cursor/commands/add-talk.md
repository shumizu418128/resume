# 登壇経験の追記

Docswell の**最新側から連続する未掲載 n 件**だけを、職務経歴書の「登壇経験」へ追記する。掲載済みより古い未掲載は対象外。

- 対象プロフィール: https://www.docswell.com/user/shumizu418128
- 編集先: `docs/README.md` の「登壇経験」表
- チャットに続いた引数（イベントURL・日付・タイトルなど）があれば、推測よりそちらを優先する

## 対象の決め方

Docswell のスライド一覧は新しい順。先頭から見て、

1. 未掲載なら対象に含める
2. 掲載済みに当たったらそこで打ち切る
3. 打ち切りより後ろの未掲載（例: VRC-LT）は無視する

先頭が掲載済みなら、何もせず「最新は掲載済み」と報告して終了する。n は 1 件に限らない。

## 手順

1. `docs/README.md` の「登壇経験」表を読む。
2. https://www.docswell.com/user/shumizu418128 を取得し、上記のルールで対象 n 件を決める。一覧に個別URLが無い場合は、必要な件だけページを検索または辿って `https://www.docswell.com/s/shumizu418128/...` を特定する。
3. 対象ごとに個別ページを開き、次を取る。
   - イベント名: headline の `発表資料 - ` 以降
   - イベントURL: `description` が URL ならそれを使う。無い、またはイベントページでない場合は connpass / 公式サイトを調べる
   - 登壇日: **イベント公式の開催日**。スライドの `datePublished` はアップロード日なので、開催日の根拠にはしない
   - スライドタイトル: 1枚目の発表タイトル。`発表資料 - ...` は使わない
4. 日付の古い順になる位置へ、対象分だけ行を挿入する。既存行は並べ替えない。
5. 追記結果を短く報告する。コミットはしない。

## 行フォーマット

既存行に合わせる。

```markdown
| [イベント名](イベントURL) | YYYY/MM/DD | [スライドタイトル](Docswell URL) |
```

- イベント名は公式表記を使う。Docswell の見出しを独自に整形しない
- 日付は `YYYY/MM/DD`
- 同じスライドを別イベントで再利用している場合のみ、スライド欄は `(既存イベント名と同じスライド）` とする。Docswell に新規アップロードがある行には使わない

## やってはいけないこと

- 掲載済みより古い未掲載スライド（例: VRC-LT）の追記・埋め戻し
- 既存行の削除・書き換え（URL欠落の補完をユーザーが明示した場合を除く）
- テックブログ欄や他セクションへの変更
- 開催日が取れない行の推測追記。その場合は確認事項だけ返す
- PDF ビルド・lint・コミット
